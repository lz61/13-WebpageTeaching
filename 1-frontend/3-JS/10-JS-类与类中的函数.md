1.JS数据结构之二(之一是数组): 类.

2.研究类的方法: "创初读修"

3.对于类本身:

创建类+初始化类:

```
class [className]{
	constructor(){
		// do sth.
	}
}
```

实例:

```
class Person{
	constructor(){
		this.name="lizeng"; // this.name被称为类的实例属性
	}
}
```

4.对于创建类的变量:

创初读改.

初始化2: 创建一个类Person的变量p并初始化:

```
var p = new Person();
// 格式:
var [varName] = new [className](...);
...中的内容: 
	constructor(...){
		this.name="lizeng";
	}
constructor(...)中的参数列表.
```

5.读+改:

访问方式

```
a.b
// 实例:
p.name
```

读:

```
console.log(p.name); // 输出lizeng
```

改:

```
p.name="liruorong"; // 修改为liruorong
```

6.请汇总如上代码,创建一个名为Person的类,定义实例属性为name,初始化函数默认创建一个名字为"lizeng"的Person,新建变量p,并输出两次name,一次默认的"lizeng",一次修改后的"liruorong";

7.每个类的实例都有其独立的实例属性.

```
class Person{
	constructor(name){
		this.name=name;
	}
}
var p1 = new Person("p1"); // p1.name = "p1";
var p2 = new Person("p2"); // p2.name = "p2";
console.log(p1.name);
console.log(p2.name);
```

8.在类内定义方法并调用

方法: 创初读修

创:

```
class Person{
	... constructor
	// 创
	testOutput(){
		// 初始化+修改
		console.log("Test output!");
	}
}
var p = new Person();
// 读
p.testOutput(); // 输出: Test output!
```

事实上,在类内定义方法并调用是非常有用的行为,它可以帮助我们更好地管理代码.
