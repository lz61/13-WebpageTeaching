1.回顾: 数据结构的定义.

2.JS数据结构之二(之一是数组): 类.

3.研究类的方法: "创初读修"

4.对于类本身:

创建类+初始化类:

理论: 

```
class [className]{
	constructor(参数列表){
		// do sth.
	}
}
```

实例:

```
class Person{
	constructor(){
		this.name="lizeng"; // this.name被称为类的实例属性
	}
}
```

代码解释:

```
class [className]{
	...
}
```

定义一个类,其名字为className.

```
constructor(参数列表){
	// do sth
}
```

在这个类的变量被创建之后,自动调用该"构造函数".

constructor(参数列表)名字: 构造函数.

```
this.name: 访问当前变量内的name
```



以下通过创建类的变量的过程来详细解释构造函数.

5.真题1.

定义一个类,名字为car(注意类名用大驼峰命名法),并定义其构造函数,使得类内的year的值变为10.

答案:

```
class Car{
	constructor(){
		this.year = 0;	
	}

}
```



4.对于创建类的变量:

老套路: 创初读修.

创建与初始化: 创建一个类Person的变量p并初始化:

```
// 实例:
var p = new Person();
// 格式:
var [varName]= new [className](...);
...中的内容: 
// 回顾构造函数:
在类中定义:
	constructor(...){
		this.name="lizeng";
	}
constructor(...)中的参数列表.
```

5.读+改:

访问方式

```
{className}.{类内属性}
或者
{className}["类内属性"] // 注意[]不是虚指.
// 实例:
p.name
或者
p["name"]
```

读:

```
console.log(p.name); // 输出lizeng
```

改:

```
p.name="liruorong"; // 修改p.name为liruorong
```

6.请汇总如上代码,创建一个名为Person的类,定义实例属性为name,初始化函数默认创建一个名字为"lizeng"的Person,新建变量p,并输出两次name,一次默认的"lizeng",一次修改后的"liruorong";

答案:

```
class Person{
	constructor(){
		this.name = "lizeng";
	}
}
```



7.每个类的实例都有其独立的实例属性.

```
class Person{
	constructor(name){
		this.name=name;
	}
}
var p1 = new Person("鸡汤来咯"); // p1.name = "鸡汤来咯";
var p2 = new Person("哪吒之魔童降世"); // p2.name = "哪吒之魔童降世";
console.log(p1.name);
console.log(p2.name);
```

8.在类内定义方法并调用

研究方法: 创初读修

创:

```
class Person{
	constructor(){
		
	}
	// 创,在类里面创建函数不用打function
	testOutput(){
		// 初始化+修改
		console.log("Test output!");
	}
}
var p = new Person();
// 读
p.testOutput(); // 输出: Test output!
```

注1: 事实上,在类内定义方法并调用是非常有用的行为,它可以帮助我们更好地管理代码.

注2: 现在了解即可,之后在撰写Angular和ts代码时,就知道为什么要在类中定义方法并调用了.
