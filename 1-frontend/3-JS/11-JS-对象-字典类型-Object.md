1.对象类型(很常用)

研究对象类型变量的方法: "创初读修"

创:

```
var x = new Object();
```

初:

```
x={}; // 空对象
x={name:'鸡汤来咯',age:-1,weight:200}; 
```

语法:

```
x={
	[属性名1]:[属性值1],
	[属性名2]:[属性值2],
	[属性名3]:[属性值3],
	...
}
```

事实上,存储的是键值对.

创+初:

```
var x = {name: "鸡汤来咯"};
```

读:

访问方式类似类:

```
x.name; // 返回"鸡汤来咯"
```

修:

```
x.name="王大队长";
```
