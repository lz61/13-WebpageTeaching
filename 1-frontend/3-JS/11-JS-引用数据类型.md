```

```

初:

```
x={}; // 空对象
x={name:'鸡汤来咯',age:-1,weight:200}; // 
```

读:

访问方式类似类:

```
x.name; // 返回"鸡汤来咯"
```

修:

```
x.name="王大队长";
```
