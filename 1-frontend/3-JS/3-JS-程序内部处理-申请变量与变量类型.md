变量: 是用于存储信息的容器.

1.申请变量(声明变量)

注意: 这里是声明变量时使用的语句,不代表变量自己的类型.

```
var x
[变量类型] [变量名]
```

var: variable

不同的两种变量类型:

```
let const
目前只作了解即可.
```

2.给变量赋值(变量初始化)

```
x=1
console.log(x);
```



3.在申请的同时给变量赋值

```
var x = 1;
console.log(x);
```



4.JS变量名的命名条件(有缺漏)

A.变量名可以以字母或下划线开头.

B.后续字符可以是字母,数字,下划线.

C.变量名区分大小写.

```
var a = 1;
var A = 2;
console.log(a)
console.log(A)
```

D.不能与保留字冲突.

保留字实例: var,console这种字符串.



5.JS变量的内置类型

A.数值类型:

整数: 1,3,5.

浮点数(小数): 2.2,1.2,1.3.

```
var x = 1;
var y = 2.2;
```

0.字符: 一个单位的输出内容叫字符,比如:

a,1,?,!都是一个字符.

a23: 3个字符.

B.字符串类型:

使用单引号,双引号或反引号(不常用)包括的文本.

```
var x = '';
var y = "1";
var z = `12`;
console.log(x);
...
```

C.布尔类型: 用于作逻辑判断(之后会有用,这里先不用太清楚知道).

值: true or false.

注意变量名,要"词可达意".

驼峰命名法.
