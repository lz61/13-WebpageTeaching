a,1,?,!都是一个字符.

变量: 是用于存储信息的容器.

1.申请变量(声明变量)

注意: 这里是声明变量时使用的语句,不代表变量自己的类型.

```
var x
[变量类型] [变量名]
```

不同的两种变量类型:

```
let const
目前只作了解即可.
```

2.给变量赋值(变量初始化)

```
x=1
```



3.在申请的同时给变量赋值

```
var x = 1
console.log("x=",x);
```



4.JS变量名的命名条件(有缺漏)

A.变量名可以以字母或下划线开头.

B.后续字符可以是字母,数字,下划线.

C.变量名区分大小写.

```
var z = `789`;
var Z = "123";
console.log("z=",z)
console.log("Z=",Z)
```

D.不能与保留字冲突.

保留字实例: var,console这种字符串.



5.JS变量的内置类型

A.数值类型:

整数: 1,3,5.

浮点数: 2.2,1.2,1.3.

```
var x = 1;
var y = 2.2;
```

B.字符串类型:

使用单引号,双引号或反引号(不常用)包括的文本.

```
var x = '123';
var y = "456";
var z = `789`;
```

C.布尔类型: 用于作逻辑判断(之后会有用,这里先不用太清楚知道).

值: true or false.

D.字符串: 这里不细讲,只需要知道:

创建: 

```
var x;
```



赋值or修改: 使用双引号、单引号或反引号.

```
x="123";
```



读取:

```
x
```
