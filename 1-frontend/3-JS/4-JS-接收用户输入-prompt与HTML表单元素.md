prompt解释:

```
prompt("参数")
返回值: 用户输入的内容(字符串类型的值)
注意区分: "100" 100
参数: 在跳出该输入框的时候显示的内容
注意: prompt最好只接收一个参数,尽量不要用多个参数.
```
