2.JS输出内容:

常用的两种方式:

```
alert("你想输出的内容");
console.log("你想输出的内容");
```

实例:

```
<html>
	<head>
		<script>
		alert("我是傻瓜!哈哈哈哈");
		console.log("看到这条消息,不转不是中国人");
		</script>
	</head>
	<body>
	</body>
</html>
```

提问: 这是哪种JS?

body-JS? head-JS? 外部JS?

答案: 因为是在head里的JS,所以是head-JS.
