7.逗号的作用之一: 分割语句,顺次执行,返回最后一个表达式的结果.

```
var sum=5;
var pad=5;
pad = ++sum, pad++, ++pad;
// pad = ++ sum; pad++; ++pad;

// pad=6,sum=6

// pad=8,sum=6
console.log("pad=",pad);
console.log("sum=",sum);
```

A.从左向右依次执行

B.整个表达式的结果是最后一个表达式的结果
