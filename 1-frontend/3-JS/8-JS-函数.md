1.函数的定义与调用

函数的定义:

```
function [函数名](参数列表){
	// do sth.
	return ...; // js不支持多个返回值,请只返回一个值
}
```

参数列表的格式:

A.可以没有参数.

B.格式:

```
参数a,参数b,参数c...
```

函数的调用:

```
[function_name](参数列表);
返回值: return 后面的东西.
参数列表: 实例化即可.
```



2.函数定义并使用的实例:

实例1:使用返回值的函数与函数的调用

```
function test(){
    return 1;
}

// 函数的执行顺序:
先调用函数
再返回函数的返回值
最后令值=x
// 函数的调用
var x = test(); // x=1

// 可以看到,test()的写法和prompt("...")函数很类似.
console.log(x);
```

教学: 记得当面手写一遍代码.

实例2: 有参数的函数

```
function test(n){
	return n*2;
}
// 调用test(n):,实例化n为1.
var x = test(1); // x=2
```



注3: 函数遇到return语句时,会直接return,不再执行下面的语句.

```
function test(){
	return 1;
	return 2;
	// 事实上返回1,因为return 1直接结束了函数的执行
}
```

6.函数命名方法: 驼峰命名法(推荐使用该命名方法)

大驼峰命名法: 所有单词的首字母大写.

小驼峰命名法: 大驼峰+例外: 首个单词的首字母小写.

注1: 函数、变量名一般使用小驼峰命名法.

注2: 类名一般使用大驼峰命名法.(学到类就懂了)



7.新手常见错误1: 希望通过函数改变传入的变量的值.

题外话:函数是否能改变传入它的值?

测试代码:

```
function tryToChangeXButFailed(x){
    x = 2;
}

var x = 1;
tryToChangeXButFailed(x);
console.log(x); // 事实上还是输出1
```

事实上,我们传给函数的值是原始值的复制,并不是原始的那个值.

对于我们目前学过的数据类型(数值、字符串、布尔),如果传入的值是这些类型,都是不能改变传入的值的.但是对于不同的数据类型,需要分类讨论.这是一件很复杂的事情.

规则: 对于目前我们学过的变量，函数并不能改变传入函数的变量!

答案: JS函数目前不能改变传入的值.

注: 原理之后会解释,不过目前请不要尝试在js的函数中改变变量的值.





8.强制类型转换函数

A. Number(): 强制将类型转换为数字.

实例:

```
var x="123";
var y = Number(x); // y=123;
```

B. String(): 强制将原类型转换为String.

```
var x = 123;
var y = String(x); // y="123";
```

注1: Number和String的函数名都是首字母大写,注意区分首字母大小写.

11.真题1.(太难,不要做)

```
编写程序,自定义一个函数:
判断:
输入的正整数是否为素数.
输出:是否为素数.
```

请重新撰写一遍函数,并自行测试自己定义的函数是否正确.



答案: 判断一个值是否为素数的程序:

```
function isPrime(n){
	if(n==1) return false;
	for(var i=2;i<n;i++){
		if(n%i==0)
			return false;
	}
	return true;
}
```



12.真题2

```
101-110内所有的素数.
```

目标: 只要调用该函数,就能输出101-110内所有的素数.

答案:

```

	...// 同上
```
