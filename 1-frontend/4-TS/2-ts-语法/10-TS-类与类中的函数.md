1.回顾: js类的定义:

实例:

```
class Person(){
	constructor{
		this.name = "lizeng";
	}
}
```

可以看到,在js中申请类内变量(一般叫其成员变量),不需要提前声明.



2.ts类的定义:

```
class Person{
	name:string;	// 申请类内变量,不需要var
	constructor(){
		this.name = "lizeng";
	}
}
```

语法:

```
class [className]{
	// 申请类内变量
	[varName1] : [varType1];
	[varName2] : [varType2];
	constructor(){
	
	}
}
```
