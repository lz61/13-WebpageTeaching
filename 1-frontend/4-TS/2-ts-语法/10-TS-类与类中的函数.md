事实上,js中的类是一种特殊的js对象,属于js的语法糖.

1.回顾: js类的定义:

实例:

```
class Person(){
	constructor{
		this.name = "lizeng";
	}
}
```

可以看到,在js中申请类内变量(一般叫其成员变量),不需要提前声明.



2.ts类的定义与初始化(推荐):

实例:

```
class Person{
	name:string;	// 申请类内变量,不需要var
	constructor(){
		// 在使用类内变量前,需要先声明其类型
		this.name = "lizeng";
	}
}
```

语法:

```
class [className]{
	// 申请类内变量
	[varName1] : [varType1];
	[varName2] : [varType2];
	// 类内变量的初始化
	constructor(){
		// 使用构造函数
	}
}
```



3.ts类内变量初始化的另一种方式(不推荐):

```
class [className]{
	[varName1] = [value1];
	[varName2] = [value2];
	// ...
}
```

实例:

```
class TestComponent{
	x = 1;
	y = "123";
	// ...
}
```

好处: 将声明和初始化结合,非常的方便.

坏处: 将声明和初始化结合,在constructor()中干的事才是真正的初始化.
