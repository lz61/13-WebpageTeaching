1.循环的语法基本与JS保持一致,以下用循环的题目验证.

2.题目1:

使用TS求解: 

sum=1+2+3...+n,用户会从键盘输入n.

答案:

```
// 申请变量
var n=0,sum=0;

// 读取用户输入
n=Number(prompt("请输入n"));

// 内部处理逻辑
for(var i=1;i<=n;i++){
	sum+=i;
}

// 输出sum
console.log("sum=",sum);
```
