2.题目1:

使用TS求解: 

sum=1+2+3...+n,用户会从键盘输入n.

答案:

```
// 申请变量
var n=0,sum=0;

// 读取用户输入
n=Number(prompt("请输入n"));

// 内部处理逻辑
for(var i=1;i<=n;i++){
	sum+=i;
}

// 输出sum
console.log("sum=",sum);
```

4.题目3

撰写一个函数,

输入: 一个整数

输出: 其百位数，十位数，个位数,放到数组中输出

答案:

```
function getNum(input){
	var x = new Array(3);
	x[2]=input%10; // 个位数
	x[1]=((x-x[2])/10)%10;
	x[0]= (x-x[1]*10-x[2])/100;//百位数
}
```
