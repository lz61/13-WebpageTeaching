下面我们要把用户输入的数据永久保存到硬盘上,为此我们要创建一个数据库.

数据库: 创初读修.

1.在/app目录创建数据库文件db.json:

文件内容:

```
{
    "employees": []
}
```



2.启动数据库

基础手段:

使用 `json-server` 结合 `db.json` 文件模拟一个服务器.

A.`json-server`简要说明:

用于模拟后端服务器,并不能真正完成后端需要的工作,没有那么智能.

B.使用json-server启动db.json:

```
json-server --watch db.json --port 300
```

作用: 在3000端口上启动文件: db.json.
